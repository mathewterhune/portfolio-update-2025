# 🌐 Personal Portfolio Website

A dynamic, professional, and responsive portfolio website built with **React** and **Tailwind CSS**. This site showcases my academic background, technical skills, professional experience, and major projects as a recent Computer Science graduate from the University of Victoria.

## 🚀 Features

- 🧠 **About Me Section**: Brief personal introduction and academic journey.
- 💼 **Experience Timeline**: Detailed co-op and research experience with bullet-point highlights.
- 🎓 **Education**: Academic credentials including degree, institution, and timeline.
- 💻 **Projects Showcase**: Displays key software projects with tags, descriptions, and links to GitHub and demos.
- 🛠️ **Skills Matrix**: Categorized technical skillsets (Languages, Tools, Frameworks, etc.).
- 🌌 **Animated Particle Background**: A visually appealing background using `tsparticles`.

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Framer Motion
- **Particle Animation**: `tsparticles`
- **Package Management**: npm
